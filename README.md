# volatility-trading
Modeling volatility to manage risk and identify high expected value trading opportunities

# Installing and Setting up a virtual environment
`requirements.txt` contains all the dependencies required to run the volatility trading models.
Run the following commands to set up a virtual environment and install the required packages:

```bash
uv venv <env_name>
source <venv_name>/bin/activate
uv pip install -r requirements.txt
